# Country Mi Campo Landing

Landing page comercial para Country Mi Campo, orientada a presentar el barrio de forma clara, visual y confiable.

Demo en vivo: [countrymicampo.vercel.app](https://countrymicampo.vercel.app)

## Resumen

Este proyecto fue desarrollado como una landing estática enfocada en:

- mostrar el entorno y los espacios reales del lugar
- destacar amenities, ubicación y formas de contacto
- ordenar el mensaje comercial con un tono más claro y profesional
- publicar una versión liviana y fácil de mantener en Vercel

## Qué incluye

- Hero principal con imagen destacada y efecto parallax suave
- Sección de propuesta y amenities
- Galería con imágenes reales del predio
- Bloque de posicionamiento comercial
- Opiniones y prueba social
- Información de inversión, ubicación y contacto
- Publicación online en Vercel

## Stack

- HTML5
- CSS3
- JavaScript vanilla
- Vercel para deploy

## Objetivo del proyecto

La meta fue transformar una presentación básica en una landing más sólida para uso comercial, con mejor jerarquía visual, textos más consistentes y una navegación simple para orientar visitas y consultas.
